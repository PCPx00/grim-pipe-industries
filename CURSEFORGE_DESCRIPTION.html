Items. Fluids. Energy. Chemicals. One clean pipe.

Grim Pipe Industries is a small, black-and-purple pipe mod that stays out of your way. Place a pipe, flip the end you want to pull from to Input with the Reaper Wrench, and you're done. Every pipe is the same clean size. You can stack several kinds into one block, so an item pipe, a fluid pipe and an energy pipe can all connect to the same side of one machine. Speed comes from cards you put only in the Input end, never in the pipes in between. Built to match Grim Soul Industries.

Reaper Item Pipe
Moves items from any inventory: chests, machines, AE2, Refined Storage and more.

Reaper Fluid Pipe
Moves any fluid from any tank.

Reaper Energy Pipe
Moves Forge Energy (FE) from any generator or battery.

Reaper Chemical Pipe
Moves Mekanism gases, infuse types, pigments and slurries. Only needed with Mekanism.

Reaper Omni Pipe
Moves all four on a single pipe.

Pipes store nothing, so nothing can get stuck, mixed or lost inside them. Items arrive instantly with no item entities to render, and outputs are served round-robin so every machine gets its share. Pipes that are moving something show a soft flowing glow.

Right-click a placed pipe with a different pipe and both share that block, each as its own strand. A bundle can hold any mix of the five, and every strand connects to the same face of a chest or machine on its own. Pull drops out of a Virtualization Chamber and push power into it, both through one face.

  • Every pipe uses the same casing size. Shared strands show as neat colored bands, always in the same order, so a bundle lines up perfectly with a single pipe.
  • Each arm only shows the strands that actually go that way.
  • Sneak-right-click the face of a chest that already has a pipe in front of it to add another strand there directly.

Reaper Wrench

  • Click a pipe end: switch it between Output (purple plate) and Input (gold plate, pulls from the block).
  • Sneak-click an end or click a link between pipes: disconnect that side.
  • Click a pipe's core on a side with no arm: reconnect it.
  • Sneak-click a core: take that one strand out of the block.

The wrench targets the exact band you click. Wrenches from other mods (tagged c:tools/wrench) work too.

Empty-hand right-click an Input end to open its screen:

  • Speed card slot: drop a card in or take it out, and see the exact speed that end runs at.
  • 9-slot filter: click with an item to add it (your item isn't used up). Buckets filter fluids.
  • Whitelist, Blacklist or Void (pull everything and delete what's in the filter).
  • Redstone control: Always on, Needs signal or Stops with signal.
  • Distribution: Round-robin, Nearest first or Random.
  • Three styles: Reaper, Vanilla and Dark, switched from the corner button, the same as Grim Soul Industries.

Empty-hand right-click an Output end to set a priority (higher fills first, equal priorities share round-robin) and a Whitelist / Blacklist filter, so one line can sort items and fluids into the right chests.

Sneak-click a pipe with an empty hand to see every end of that block in one screen. Click an end there to open it, right-click to switch Input / Output.

  • Exact match (book button on every filter): off ignores enchantments, damage and contents; on must match exactly.
  • Reaper Tag Filter: put it in a filter slot and type rules: #c:ingots, #c:ores/*, @mekanism, *_log. It shows what it matches as you type, and works for fluids too.
  • Reaper Imprint: sneak-click an end to copy its settings, then click other ends to paste them. Handy for big sorting walls.

  • Soul Link: click one pipe, then another anywhere in the same dimension, and their networks become one with no pipes in between. Both ends must be loaded. Reusable.
  • Facades: sneak-right-click a pipe with a full block to hide it inside. It keeps working; the wrench takes the block back.
  • Reaper Field Guide: a 10-page in-game book that teaches the whole mod.
  • Jade and WTHIT tooltips, and JEI info pages for every item.
  • On servers, the screens show the server's speeds.

Speed cards use the Grim Soul Industries tiers and colors. Only Input ends need one, so a single card on the end that pulls runs a whole line of plain pipes at full speed. The card's color shows on the end plate. With Grim Soul Industries installed, a Grim Soul speed card also crafts the Soulforged card.

Hollow → Whispering → Restless → Wraithbound → Soulforged

  • Hollow (no card): 8 items/s, 100 mB/t fluid, 1,000 FE/t
  • Whispering: 32 items/s, 400 mB/t, 8,000 FE/t
  • Restless: 128 items/s, 1,600 mB/t, 64,000 FE/t
  • Wraithbound: 640 items/s, 6,400 mB/t, 512,000 FE/t
  • Soulforged: 5,120 items/s, 25,600 mB/t, 4,096,000 FE/t

Every number is configurable in config/grimpipes-common.toml.

  • Pipe blocks never tick. One manager per world runs whole networks; the work grows with pipe ends, not pipe blocks.
  • Networks are built once and cached, and a change only rebuilds what it touches.
  • Idle ends back off automatically and wake the moment you change their card or filter.
  • Baked into the chunk mesh like normal blocks: no per-frame cost, no entities, no flying items. Never loads chunks.
  • Measured on a real server: one network of 1,024 pipes with 32 ends costs about 0.1 ms per tick.

  • Minecraft 1.21.1, NeoForge 21.1.0+
  • Optional: Mekanism 10.7+ for the Chemical Pipe. Like Mekanism's own tubes, set the machine's side configuration to Output on the side you pull from.
  • Optional: Jade or WTHIT, JEI, Grim Soul Industries.
  • Needed on both client and server.

Works with anything that uses the standard NeoForge item, fluid and energy capabilities. Checked on a real server with Create, AE2, Refined Storage, Mekanism and Grim Soul Industries loaded together: items, fluids, energy and Liquid Experience go into and out of their storage and machines.
